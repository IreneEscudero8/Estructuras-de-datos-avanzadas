# Estructuras de Datos Avanzadas 

Este repositorio contiene las implementaciones de las 6 prácticas desarrolladas durante el curso de **Estructuras de Datos Avanzadas**. El objetivo principal es explorar y aplicar estructuras de datos complejas para optimizar el manejo y procesamiento de información.

---

## Contenido del Repositorio

A continuación se detallan las prácticas incluidas en este proyecto. Cada una se encuentra en su respectivo directorio con el código y la documentación correspondiente.

### 1. Práctica 1: Introducción y Fundamentos
Enfoque inicial en la configuración del entorno y repaso de conceptos básicos necesarios para abordar estructuras complejas.

### 2. Práctica 2: Estructuras Lineales Avanzadas
Implementación y análisis de eficiencia de estructuras lineales aplicadas a problemas específicos de búsqueda y ordenamiento.

### 3. Práctica 3: Árboles de Búsqueda
Desarrollo de árboles binarios de búsqueda y técnicas de balanceo para garantizar tiempos de operación óptimos.

### 4. Práctica 4: Estructuras Multicamino y Heaps
Uso de árboles B o estructuras similares y colas de prioridad para la gestión eficiente de grandes volúmenes de datos.

### 5. Práctica 5: Grafos y Algoritmos de Recorrido
Representación de grafos (matrices y listas de adyacencia) y ejecución de algoritmos fundamentales como BFS y DFS.

### 6. Práctica 6: Optimización y Aplicaciones Finales
Implementación de algoritmos de caminos mínimos o flujo máximo, aplicando todo lo aprendido en un caso de uso práctico.
